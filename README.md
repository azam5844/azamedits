# Aza Edits

This repository contains the styling assets for the Aza Edits project.

## Files

- `style.css` — stylesheet for the project's visual presentation.
- `README.md` — project notes and documentation.

## Getting started

1. Clone or download this repository.
2. Review `style.css`.
3. Link the stylesheet from your HTML page:

   ```html
   <link rel="stylesheet" href="style.css">
   ```

## Development

Edit `style.css` to adjust the design. A preview requires an HTML page that loads this stylesheet.
